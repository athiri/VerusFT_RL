# LLM-Generated Verus Examples

This directory contains verifiable Verus examples generated by prompting Claude Sonnet 4.5.

## Overview

This directory contains two main datasets:

1. **verismo/**: 70 examples adapted from the VeriSMo repository.
2. **verus-proof-synthesis/**: 123 examples generated from benchmarks in the Verus Proof Synthesis repository:
   - **Verus-Bench**: 43 examples from CloverBench, Diffy, MBPP, and Misc benchmarks
   - **VeruSAGE-Bench**: 80 examples from 8 real-world verification projects (AL, IR, MA, NO, NR, OS, ST, VE)

## Generation Process

### VeriSMo Dataset (verismo/) and Verus-Bench Dataset (verus-proof-synthesis/Verus-Bench)

These examples were generated from subdirectories within the VeriSMo repository using the following prompt:

> "Your goal is to generate verifiable, dependency-clean Verus examples that contain both Verus code and specifications. Follow the steps below:
>
> 1. Identify the examples in `$SUBDIRECTORY` that contain both Verus code and specifications. Please note that examples with only proofs are not applicable.
> 2. Using the examples you found in Step 1 as a reference, generate as many verifiable Verus examples as you can. Please keep them simple.
> 3. For each example you generate, run `verus $EXAMPLE_GENERATED` to check if the output is verified. If not, make changes accordingly.
> 4. Once the example is verified, save it to `$OUTPUT_DIRECTORY`."

### VeruSAGE-Bench Dataset (verus-proof-synthesis/VeruSAGE-Bench)

Since the VeruSAGE-Bench contains multi-file dependencies, the examples were generated using the following prompt:

> "Your goal is to generate verifiable, dependency-clean Verus examples that contain both Verus code and specifications. Follow the steps below:
>
> 1. Identify top 10 shortest examples in `$BENCHMARK_DIR/verified` that contain both Verus code and specifications. If all the files in directory are >100 lines, end the task and do not generate any examples.
> 2. Using the examples you found in Step 1 as a reference, generate as many verifiable Verus examples as you can. Please keep them simple.
> 3. For each example you generate, run `verus $EXAMPLE_GENERATED` to check if the output is verified.
> 4. Once the example is verified, save it to `$OUTPUT_DIRECTORY`."

Note: AC (Anvil-advanced) from the original VeruSAGE-Bench is ablated from generation because all files are >400 lines.
