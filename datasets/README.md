# Verus Verification Datasets

This directory contains consolidated Verus verification examples from multiple sources, totaling **9,579 verified Rust files** with formal specifications.

## Overview

| Dataset | Files | Source | Description |
|---------|-------|--------|-------------|
| `coq_translation/` | 234 | Coq proofs | Verus translations of Coq verification examples |
| `agent_generated/` | 26 | CortenMM | LLM-generated examples from memory management specs |
| `llm_extracted/` | 9,126 | LLM refinement | Iteratively refined verified examples |
| `llm_generated/` | 193 | VeriSMo + Benchmarks | Curated LLM-generated verification examples |

**Total: 9,579 verified Verus examples**

## Dataset Details

### 1. `coq_translation/` (234 files)

Verus translations derived from Coq verification proofs covering:

- **VFA (Verified Functional Algorithms)**: Data structures (BST, AVL, red-black trees), sorting algorithms, graph algorithms, dynamic programming
- **QuickChick (QC)**: Property-based testing, type classes, generators, shrinking strategies
- **Software Foundations**: Logic, induction, type systems, Hoare logic

**Example categories:**
- `vfa_*.rs` - Verified functional algorithms
- `qc_*.rs` - QuickChick testing patterns
- `*_verus.rs` - Software foundations translations

### 3. `llm_extracted/` (9,126 files)

Large-scale dataset of LLM-iteratively refined Verus examples. Each file was verified through multiple refinement iterations.

**Naming convention:** `example_NNNNN.rs` (e.g., `example_00228.rs` to `example_09167.rs`)

**Characteristics:**
- Contains comments marking LLM modifications: `/* code modified by LLM (iteration N): ... */`
- Loop invariants, preconditions, postconditions
- Various verification patterns (arrays, sequences, predicates)

## Usage

All `.rs` files are standalone Verus programs that can be verified with:

```bash
verus <filename>.rs
```

### Example

```rust
// From llm_generated/verus-proof-synthesis/Verus-Bench/CloverBench/04_gcd.rs
use vstd::prelude::*;

verus! {
    pub open spec fn gcd(a: nat, b: nat) -> nat
        decreases a + b
    {
        if b == 0 { a }
        else if a == 0 { b }
        else if a >= b { gcd((a - b) as nat, b) }
        else { gcd(a, (b - a) as nat) }
    }
}
```
